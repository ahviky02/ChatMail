## Introduction

ChatMail is a real-time chat application built using modern web technologies. It leverages WebRTC for real-time communication and Socket.io for signaling between clients. This repository provides both the frontend and backend implementation for the chat application.

## Features

- Real-time chat using Socket.io
- Signaling using Socket.io
- User-friendly interface with React
- Backend server with Node.js and Express

## Used Technologies

- **React.js**: A JavaScript library for building user interfaces.
- **Node.js**: A JavaScript runtime built on Chrome's V8 JavaScript engine.
- **Express.js**: A web application framework for Node.js.
- **Socket.io**: A library for real-time web applications.
- **Tailwind CSS**: A utility-first CSS framework for styling.

## Installation

To run this project locally, follow these steps:

### Backend

1. Clone the repository:
   ```sh
   git clone https://github.com/ahviky02/ChatMail.git
   cd ChatMail
   ```

2. Install the dependencies:
   ```sh
   npm install
   ```

3. Start the backend server:
   ```sh
   cd backend
   npm start
   ```

### Frontend

1. Navigate to the frontend directory:
   ```sh
   cd ../frontend
   ```

2. Install the dependencies:
   ```sh
   npm install
   ```

3. Start the frontend application:
   ```sh
   npm run dev
   ```

4. Open your browser and navigate to `http://localhost:5173`.

## Usage

1. Open the application in two different browser windows or tabs.
2. Enjoy the real-time chat application!
